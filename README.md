# ⚡ Tesla-Energieübertragung (TeslaEnergie)

Fehlermeldungen und Vorschläge für die Satisfactory-Mod **Tesla-Energieübertragung**.
*Bug reports and suggestions for the Satisfactory mod **Tesla-Energieübertragung** (wireless power with Tesla towers).*

Die Mod selbst gibt es im Satisfactory Mod Manager bzw. auf [ficsit.app](https://ficsit.app).
Diese Seite enthält keinen Quellcode, sie dient nur als Briefkasten.

## Etwas melden / Report something

➡️ **[Neue Meldung erstellen / New issue](../../issues/new/choose)**

- 🐞 **Fehler melden:** Etwas funktioniert nicht wie beschrieben.
- 💡 **Vorschlag:** Eine Idee oder ein Wunsch für eine spätere Version.

Englisch ist willkommen. *English is welcome.*

## Hinweise

- Bitte zuerst schauen, ob es dieselbe Meldung schon gibt.
- Bei Fehlern hilft die Logdatei sehr. Sie liegt hier:
  `%LOCALAPPDATA%\FactoryGame\Saved\Logs\FactoryGame.log`
  (bei Servern im Ordner `FactoryGame/Saved/Logs/` des Servers).
- Vor dem Hochladen der Logdatei bitte kurz hineinschauen: Sie kann deinen Windows-Benutzernamen
  und Servernamen enthalten.
